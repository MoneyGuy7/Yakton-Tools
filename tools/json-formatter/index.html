Common questions

Is this tool free?

Yes. There is no account or paid API requirement for ordinary use.

Does my input get uploaded?

Most tools work locally in your browser. The QR code generator uses a third-party QR service, so do not enter private or confidential text there. Image tools use browser canvas locally.

Can I use it on mobile?

The interface is responsive and supports modern mobile browsers. Exact behavior depends on browser support and device memory, especially for large images.
